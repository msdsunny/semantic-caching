Using Semantic Caching with Amazon S3 to Reduce LLM Costs
Getting Started

In generative AI applications, generating new responses for similar user queries can increase latency and increase LLM inference costs. Users often phrase the same question in different ways, for example, “What is the pricing?” and “How much does it cost?”

Semantic caching addresses this issue by storing previously generated responses, along with their corresponding vector embeddings. When a new query is submitted, the system checks the cache for semantically similar queries and returns the cached response if the similarity is above a defined threshold. This reduces unnecessary model invocations, improves response times, and lowers costs, making our AI applications faster and more efficient.

Semantic caching is particularly useful for queries that repeat with minor variations in wording, such as FAQ systems, knowledge base search, or customer support chatbots. By using embeddings to encode the semantic content of a query rather than relying on an exact text match, semantic caching allows the system to identify queries with similar embeddings.

The distance metric is key to this process; it quantifies how close the new query vector is to existing vectors in the cache. For example, a cosine distance of 0 indicates an exact semantic match, while higher values indicate lower similarity. We’ll use a threshold to determine when a cached response is similar enough to reuse, allowing us to balance accuracy with efficiency.

Create an S3 Vector Bucket

Amazon S3 vector buckets are specialized for storing vector embeddings, numeric representations of data such as text, images, or audio used in AI and machine learning applications. These buckets provide scalable, low-latency storage optimized for high-dimensional vectors and integrate with services such as Amazon Bedrock. A vector bucket functions as a vector store for embedding storage and retrieval, supporting tasks such as semantic search, recommendation systems, and knowledge base retrieval.

In this task, we’ll create an S3 vector bucket and a vector index to serve as the semantic cache for our generative AI application. This vector store will be used to persist embeddings of user queries along with their generated responses. Create a Lambda Function

AWS Lambda allows us to execute code without maintaining or deploying servers. It is a core component of serverless architecture. It charges consumers for the number of requests and the compute time used, rather than for preallocated server resources. Lambda supports various programming languages, including Python, Java, Go, and Ruby.

In this task, you will create a Lambda function that implements semantic caching. It generates embeddings for user queries using the Bedrock embedding model and queries the S3 vector index for embeddings similar to the incoming query. Similarity is measured using cosine distance, which quantifies how close two embedding vectors are. A distance of 0 indicates identical vectors, while larger values indicate lower similarity.

The Lambda uses a similarity threshold of 0.90 to decide when a cached response is close enough to reuse. If no match meets the threshold, it invokes a Bedrock LLM, stores the new query and response in the cache, and returns the result, improving response speed and reducing unnecessary model calls.

import boto3
import json
import os
import uuid
from botocore.exceptions import ClientError

# --- Configuration ---
# Set these as Environment Variables in your Lambda Configuration
BUCKET_NAME = "semantic-cache-app"
INDEX_NAME = "cache-index"
EMBEDDING_MODEL_ID = "amazon.titan-embed-text-v2:0"
LLM_MODEL_ID = "amazon.nova-pro-v1:0"
SIMILARITY_THRESHOLD = 0.90 # 0.0 to 1.0 (Exact match) 

# --- Clients ---
bedrock = boto3.client('bedrock-runtime')
s3_vectors = boto3.client('s3vectors')

def lambda_handler(event, context):
   try:
       # 1. Parse Input
       # Assuming API Gateway passes body as a JSON string
       body = json.loads(event.get('body', '{}'))
       user_prompt = body.get('prompt', '')
      
       if not user_prompt:
           return {"statusCode": 400, "body": json.dumps({"error": "No prompt provided"})}

       print(f"Received Prompt: {user_prompt[:50]}...")

       # 2. Create Vector Embedding for the Prompt
       # We need this for both querying the cache AND storing a new result
       prompt_vector = generate_embedding(user_prompt)

       # 3. Check S3 Vector Cache
       cached_response = check_cache(prompt_vector)
      
       if cached_response:
           print("CACHE HIT")
           return {
               "statusCode": 200,
               "headers": {"X-Cache-Status": "HIT"},
               "body": json.dumps({"response": cached_response})
           }

       # 4. Cache Miss - Generate New Response
       print("CACHE MISS - Invoking LLM")
       llm_response = generate_llm_response(user_prompt)

       # 5. Store in S3 Vector Cache (Background)
       # We store the prompt vector + the LLM answer as metadata
       save_to_cache(user_prompt, prompt_vector, llm_response)

       return {
           "statusCode": 200,
           "headers": {"X-Cache-Status": "MISS"},
           "body": json.dumps({"response": llm_response})
       }

   except Exception as e:
       print(f"Error: {str(e)}")
       return {"statusCode": 500, "body": json.dumps({"error": str(e)})}

# --- Helper Functions ---

def generate_embedding(text):
   """Generates a vector using Titan Embeddings v2"""
   response = bedrock.invoke_model(
       modelId=EMBEDDING_MODEL_ID,
       body=json.dumps({"inputText": text})
   )
   response_body = json.loads(response['body'].read())
   # Titan v2 returns the embedding in 'embedding'
   return response_body['embedding']

def check_cache(vector):
   """
   Queries S3 Vectors.
   NOTE: S3 Vectors returns 'distance' for both Cosine and Euclidean.
   For Cosine: Distance = 1.0 - Similarity.
   So a distance of 0.0 is a PERFECT MATCH.
   """
   try:
       response = s3_vectors.query_vectors(
           vectorBucketName=BUCKET_NAME,
           indexName=INDEX_NAME,
           queryVector={'float32': vector}, # Note the strict typing 'float32'
           topK=1,
           returnMetadata=True,
           returnDistance=True
       )

       if not response.get('vectors'):
           return None

       match = response['vectors'][0]
       # Check your specific index config. Assuming 'score' here.
       distance = match.get('distance', 1.0)
      
       print(f"Nearest Neighbor Distance: {distance}")

       CACHE_THRESHOLD = 1.0 - SIMILARITY_THRESHOLD
      
       if distance <= CACHE_THRESHOLD:
         print("Distance is low enough -> CACHE HIT")
         return match.get('metadata', {}).get('answer')
          
       print("Distance too high -> CACHE MISS")
       return None

   except ClientError as e:
       print(f"S3 Vector Query Error: {e}")
       return None

def save_to_cache(prompt, vector, answer):
   """Writes the new Q&A pair to S3 Vectors"""
   try:
       # S3 Vectors requires a unique key for the object
       unique_key = str(uuid.uuid4())
      
       s3_vectors.put_vectors(
           vectorBucketName=BUCKET_NAME,
           indexName=INDEX_NAME,
           vectors=[{
               "key": unique_key,
               "data": {"float32": vector},
               "metadata": {
                   # We store the original prompt and the answer
                   # Metadata values must be strings
                   "original_prompt": prompt,
                   "answer": answer[:1000]
               }
           }]
       )
       print(f"Saved new vector to cache with key: {unique_key}")
   except Exception as e:
       # Don't fail the user request if caching fails
       print(f"Failed to save to cache: {e}")

def generate_llm_response(prompt):
    """Invoke Amazon Nova Pro via Bedrock"""
    body = json.dumps({
        "messages": [
            {
                "role": "user",
                "content": [
                    {"text": prompt}
                ]
            }
        ]
    })

    response = bedrock.invoke_model(
        modelId=LLM_MODEL_ID,
        body=body
    )

    result = json.loads(response["body"].read())

    # Nova Pro actual response parsing
    return result["output"]["message"]["content"][0]["text"]
